[16届蓝桥杯省赛无忧班（C&C++ 组）4期 - 蓝泽的秘密邮件 - 蓝桥云课](https://www.lanqiao.cn/courses/44493/learning/?id=3537891&compatibility=false)
在一个城市，蓝泽是一个著名的侦探，他手上有一份秘密情报——一串由数字组成的密码。这个密码是一个由 n 个整数组成的数组 a。密码的解析从零开始，即第一个元素是 a0​，第二个元素是 a1​，依此类推。然而，这个密码有个特殊的设定，只有当偶数位置（a0​，a2​，a4​，......）的元素之和达到最大值，才能解开密码的真正含义。蓝泽可以通过反转其中一个子数组（连续子段）来尝试改变这个和，**找出可以使得偶数位置的元素之和最大的情况。** 第一行包含一个整数 —— 数组 a 的长度。第二行包含 n 个整数 a0​，a1​，...，an−1​。
```c++
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int maxn = 2e5 + 10;
ll a[maxn] = {};

void solve() //贪心+最大子段和
{
  int n; cin >> n;
  for(int i = 1; i <= n; i++) cin >> a[i];
  //先考虑初始偶数位置上的和
  ll initial_sum = 0;
  for(int i = 1; i <= n; i += 2) initial_sum += a[i];
  
  //找出从右侧两两奇偶位置数时产生的最大变化量差值
  ll dif = 0, sum = 0;
  for(int i = 3; i <= n; i += 2)
  {
  	ll val = a[i - 1] - a[i];
  	sum = max(0ll, sum + val);
  	dif = max(dif, sum);
  }
  
  //找出从左侧两两奇偶位置数时产生的最大变化量差值
  sum = 0;
  for(int i = 1; i + 1 <= n; i += 2)
  {
  	ll val = a[i + 1] - a[i];
  	sum = max(0ll, sum + val);
  	dif = max(dif, sum);
  }
  
  //更新找到最大变化量差值的一个区间对应的dif与原初值相加即是最优
  cout << initial_sum + dif << endl;

}

int main()
{
  ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);  

  solve();

  return 0;
}
```

给定两个正整数 n，m，请你求出 Cnm​，由于这个数可能很大，你只需要输出这个数末尾有多少个零。第一行输入一个正整数 T，表示测试数据的组数。接下来 T 行，每行两个整数 n,m，含义如问题描述所示。

![[Pasted image 20251005162840.png]]

```c++
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
int t, m, n;

int res(int n, int m)
{
	int cnt2 = 0, cnt5 = 0;
	// 分别统计分子分母中2和5的因子数量，通过因子计数相减得到净数量
	for(int i = n; i >= n - m + 1; i--)
	{
		int x = i;
		while(x % 2 == 0) cnt2++, x /= 2;
		while(x % 5 == 0) cnt5++, x /= 5;
	}
	
	for(int i = 1; i <= m; i++)
	{
		int x = i;
		while(x % 2 == 0) cnt2--, x /= 2;
		while(x % 5 == 0) cnt5--, x /= 5;
	}
	return (cnt2 <= cnt5 ? cnt2 : cnt5);
}

void solve()
{
  cin >> t;
  while(t--)
  {
    cin >> n >> m;
    cout << res(n, m) << '\n';
  }
}

int main()
{
  ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);

  solve();

  return 0;
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int maxn = 2e3 + 10;

int a[maxn] = {};
int n;

void solve() //找出出现次数最多的数字，计算最多会产生多少个 0，用鸽巢原理判断这些 0 是否能被非零数字隔开
{ 
  cin >> n;
  for(int i = 1; i <= 2 * n; i++) cin >> a[i];
  sort(a + 1, a + 1 + 2 * n);

  int cnt = 1, max_cnt = 1;
  for(int i = 2; i <= 2 * n; i++)
  {
    if(a[i] == a[i - 1]) cnt++;
    else cnt = 1;
    max_cnt = max_cnt > cnt ? max_cnt : cnt;
  }

  int otherelement = (2 * n) - max_cnt;
  int rest_num0_pair = (max_cnt - otherelement) / 2; //消耗掉出现次数最多的某个数字剩下两两同数字佩对产生的0的对数。
  if(rest_num0_pair > n - rest_num0_pair + 1) cout << "NO\n"; // 总共n对，减去0数对的数目，剩下的非零对（n - rest_num0_pair）的数目可以产生 n - rest_num0_pair + 1个空隙
  else cout << "YES\n";
}

int main()
{
  ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
  
  int t;
  cin >> t;
  
  while(t--) solve();

  return 0;
}
```

给定一个长度为 `n` 的数组 `a`，小蓝希望从数组中选择若干个元素（可以不连续），并将它们重新排列，使得这些元素能够形成一个先严格递增然后严格递减的子序列（可以没有递增部分或递减部分）。你需要求出在满足这个条件下，最多可以选择多少个元素。
- 第一行包含一个正整数 nn，表示数组的长度。(1≤n≤10^5)
- 第二行包含 nn 个整数 a1,a2,...,an−1,an。(1≤ai≤10^5)
```c++
#include <bits/stdc++.h>
using namespace std;

const int maxn = 1e5 + 10;
int a[maxn];

void solve()
{
  int n;
  cin >> n;

  for(int i = 1; i <= n; i++) cin >> a[i];
  sort(a + 1, a + 1 + n);

  int ans = 1; //极端情况至少取一个最大值（在全数相同的情况下）

  int end = n - 1;
  while(end > 0 && a[end] == a[end + 1]) end--; //找到次大值的末尾位置

  int cnt = 1;
  for(int i = end; i >= 1; i--)
    if(a[i] == a[i - 1]) cnt++;
    else 
    {
      ans += (cnt >= 2 ? 2 : 1);
      cnt = 1;
    }

  cout << ans << '\n';
}

int main()
{
  ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);

  solve();

  return 0;
}
```
