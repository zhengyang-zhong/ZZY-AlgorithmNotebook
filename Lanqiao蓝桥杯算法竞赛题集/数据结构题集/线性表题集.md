# 单链表题目
## 单链表基础操作
### 题目
实现一个单链表，链表初始为空，支持三种操作：

1. 向链表头插入一个数；
2. 删除第 k个插入的数后面的一个数；
3. 在第 k个插入的数后插入一个数。

现在要对该链表进行 M 次操作，进行完所有操作后，从头到尾输出整个链表。

**注意**:题目中第 k 个插入的数并不是指当前链表的第 k个数。例如操作过程中一共插入了 n 个数，则按照插入的时间顺序，这 n 个数依次为：第 1 个插入的数，第 2 个插入的数，…第 n 个插入的数。

#### 输入格式

第一行包含整数 M，表示操作次数。

接下来 M 行，每行包含一个操作命令，操作命令可能为以下几种：

1. `H x`，表示向链表头插入一个数 x。
2. `D k`，表示删除第 k 个插入的数后面的数（当 k 为 0 时，表示删除头结点）。
3. `I k x`，表示在第 k 个插入的数后面插入一个数 x（此操作中 k 均大于 0）。

#### 输出格式

共一行，将整个链表从头到尾输出。

#### 数据范围

1≤M≤100000
所有操作保证合法。
### 代码
```C++
#include<iostream>

using namespace std;

const int N = 1e5+10;

int head, idx;
int element[N], nxt[N];

void initial()
{
    head = -1;// head表示头指针，-1表示表尾
    idx = 1;//idx 记录总输入次序的最新次序，从次序1开始记录总输入次数
}

//将x插入头结点
void add_to_head(int x)
{
    element[idx] = x;
    nxt[idx] = head;
    head = idx;
    idx ++;
}
//删除头结点
void delete_to_head()
{
    head = nxt[head];
}
//在k后面删除的结点
void delete_to_k(int k)
{
    nxt[k] = nxt[nxt[k]];
}
//在k后面增加1个结点
void add_to_next(int k, int x)
{
    element[idx] = x;
    nxt[idx] = nxt[k];
    nxt[k] = idx;
    idx ++;
}

int M, x, k;
char op;
int main()
{
    cin >> M;
    initial();
    while(M--)
    {
        cin >> op;
        if (op =='H')
        {
            cin >>x;
            add_to_head(x);
        }
        else if(op == 'D')
        {
            cin >> k;
            if(k == 0) delete_to_head();
            else delete_to_k(k);
        }
        else if(op == 'I')
        {
            cin >> k >> x;
            add_to_next(k, x);
        }
        
    }
    for(int i = head; i != -1; i = nxt[i])
        printf("%d ",element[i]);
    
    return 0;
}
```

## 反转单链表
### 题目
定义一个函数，输入一个链表的头结点，反转该链表并输出反转后链表的头结点。
#### 数据范围

链表长度 [0,30][0,30]。

#### 样例

```
输入:1->2->3->4->5->NULL

输出:5->4->3->2->1->NULL
```
### 代码
```C++
/**
//迭代版本
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode *pre = nullptr;
        //是用来存储反转后链表的头部（即原链表的最后一个节点，反转后成为头部）。
        //初始时设为 nullptr，因为反转后的链表末尾没有节点指向任何节点。
        ListNode *cur = head;
        //cur是用来遍历原链表的指针
        //初始时cur指向传入函数的头部head，即原链表的第一个结点
        while(cur)//进入一个循环，直到 cur 变成 nullptr（即遍历到了原链表的末尾）。
        {
            ListNode *tempnext = cur ->next;//tempnext是用来暂存当前结点cur的下一个节点
            cur->next = pre; //改变当前cur的指针指向，转向pre上一个结点
            pre = cur, cur = tempnext;// 完成操作当前结点操作后更新pre为当前cur，而cur更新为下一结点，为下一次相同操作做准备。
        }
        return pre; //返回反转后的头结点pre，成为新的head
    }
};
//递归版本
/*思路：首先我们先考虑 reverseList 函数能做什么，它可以翻转一个链表，并返回新链表的头节点，也就是原链表的尾节点。
所以我们可以先递归处理 reverseList(head->next)，这样我们可以将以head->next为头节点的链表翻转，并得到原链表的尾节点tail，此时head->next是新链表的尾节点，我们令它的next指针指向head，并将head->next指向空即可将整个链表翻转，且新链表的头节点是tail。
*/
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (!head || !head->next) return head;
        ListNode *tail = reverseList(head->next);
        head->next->next = head;
        head->next = nullptr;
        return tail;
    }
};

```
