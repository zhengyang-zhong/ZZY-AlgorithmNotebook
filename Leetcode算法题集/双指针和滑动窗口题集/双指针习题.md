- [1750. 删除字符串两端相同字符后的最短长度](https://leetcode.cn/problems/minimum-length-of-string-after-deleting-similar-ends/)
给你一个只包含字符 'a'，'b' 和 'c' 的字符串 s ，你可以执行下面这个操作（5 个步骤）任意次：
1. 选择字符串 s 一个 非空 的前缀，这个前缀的所有字符都相同。
2. 选择字符串 s 一个 非空 的后缀，这个后缀的所有字符都相同。
3. 前缀和后缀在字符串中任意位置都不能有交集。
4. 前缀和后缀包含的所有字符都要相同。
5. 同时删除前缀和后缀。
请你返回对字符串 s 执行上面操作任意次以后（可能 0 次），能得到的 最短长度 。
输入：s = "aabccabba"
输出：3
解释：最优操作序列为：
- 选择前缀 "aa" 和后缀 "a" 并删除它们，得到 s = "bccabb" 。
- 选择前缀 "b" 和后缀 "bb" 并删除它们，得到 s = "cca" 。
```cpp
class Solution {
public:
    int minimumLength(string s) {
        int head = 0, tail = s.length() - 1;
        while(head < tail && s[head] == s[tail])
        {
            char tmpc = s[head];
            while(s[head] == tmpc && head <= tail) head++;
            while(s[tail] == tmpc && head <= tail) tail--;
        }
        return tail - head + 1;
    }
};
```

- [658. 找到 K 个最接近的元素](https://leetcode.cn/problems/find-k-closest-elements/) （**二分+双指针**）
给定一个 排序好 的数组 arr ，两个整数 k 和 x ，从数组中找到最靠近 x（两数之差最小）的 k 个数。返回的结果必须要是按升序排好的。整数 a 比整数 b 更接近 x 需要满足：
|a - x| < |b - x| 或者
|a - x| == |b - x| 且 a < b
```cpp
class Solution {
public:
    vector<int> findClosestElements(vector<int>& arr, int k, int x) {
        vector<int> ans;
        int head = 0, tail = arr.size() - 1;
        
        while(tail - head + 1 > k)//循环结束后总会有k个元素符合条件，故确定好当前指针的位置关系在恰好距离k时结束，此时双指针内部的元素依次从head开始记录即可得到答案。
        {
            if(abs(arr[head] - x) <= abs(arr[tail] - x)) tail--;
            else head++;
        }

        for(head; head <= tail; head++) 
            ans.push_back(arr[head]);
        return ans;
    }
};
```


- [1471. 数组中的 k 个最强值](https://leetcode.cn/problems/the-k-strongest-values-in-an-array/)
给你一个整数数组 arr 和一个整数 k 。设 m 为数组的中位数，只要满足下述两个前提之一，就可以判定 `arr[i]` 的值比 `arr[j]` 的值更强：
- `|arr[i] - m| > |arr[j] - m|`
- `|arr[i] - m| == |arr[j] - m|，且 arr[i] > arr[j]`
请返回由数组中最强的 k 个值组成的列表。答案可以以 任意顺序 返回。中位数 是一个有序整数列表中处于中间位置的值。形式上，如果列表的长度为 n ，那么中位数就是该有序列表（下标从 0 开始）中位于 ((n - 1) / 2) 的元素。
- 例如 arr = `[6, -3, 7, 2, 11]`，n = 5：数组排序后得到 `arr = [-3, 2, 6, 7, 11]` ，数组的中间位置为 m = ((5 - 1) / 2) = 2 ，中位数 `arr[m]` 的值为 6 。
- 例如 arr = `[-7, 22, 17, 3]`，n = 4：数组排序后得到 `arr = [-7, 3, 17, 22]` ，数组的中间位置为 m = ((4 - 1) / 2) = 1 ，中位数 `arr[m]` 的值为 3 。
```cpp
class Solution {
public:
    vector<int> getStrongest(vector<int>& arr, int k) {
        vector<int> ans;
        int len = arr.size();
        sort(arr.begin(), arr.end());
        
        int mid = arr[(len - 1) >> 1];
        for(int tail = len - 1, head = 0; tail - head + 1 != len - k;)
        {
            if(mid - arr[head] <= arr[tail] - mid) ans.push_back(arr[tail--]);
            else ans.push_back(arr[head++]);
        }

        return ans;
    }
};
```

- [80. 删除有序数组中的重复项 II](https://leetcode.cn/problems/remove-duplicates-from-sorted-array-ii/)
给你一个有序数组 nums ，请你 原地 删除重复出现的元素，使得出现次数超过两次的元素只出现两次 ，返回删除后数组的新长度。不要使用额外的数组空间，你必须在 原地 修改输入数组 并在使用 O(1) 额外空间的条件下完成。
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int head = 2, tail = 2, len = nums.size();
        if(len < 3) return len;
        for(head, tail; tail < len; tail++) if(nums[head - 2] != nums[tail]) nums[head++] = nums[tail];
        return head;
    }
};
```

- [283. 移动零](https://leetcode.cn/problems/move-zeroes/) #快慢指针/HareTortoise算法  
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。请注意 ，必须在不复制数组的情况下原地对数组进行操作。
**输入:** nums = `[0,1,0,3,12]`
**输出:** `[1,3,12,0,0]`
```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        for(int fast = 0, slow = 0; fast < nums.size(); fast++)
            if(nums[fast]) // 利用快慢指针进行交换，慢指针始终指向当前存在的值为0的下标处
            {
                int tmp = nums[fast];
                nums[fast] = nums[slow];
                nums[slow] = tmp;
                slow++;
            }
    }
};
```

- [922. 按奇偶排序数组 II](https://leetcode.cn/problems/sort-array-by-parity-ii/)
给定一个非负整数数组 nums，  nums 中一半整数是 奇数 ，一半整数是 偶数 。对数组进行排序，以便当 `nums[i]` 为奇数时，i 也是 奇数 ；当 `nums[i]` 为偶数时， i 也是 偶数 。你可以返回 任何满足上述条件的数组作为答案 。
```cpp
class Solution {
public:
    vector<int> sortArrayByParityII(vector<int>& nums) {
        for(int evenp = 0, oddp = 1; evenp < nums.size(); evenp += 2)
            if(nums[evenp] % 2 == 1)
            {
                while(nums[oddp] % 2 == 1) oddp += 2;
                int tmp = nums[evenp];
                nums[evenp] = nums[oddp];
                nums[oddp] = tmp;
            }
        return nums;
    }
};
```

- [1793. 好子数组的最大分数](https://leetcode.cn/problems/maximum-score-of-a-good-subarray/)
给你一个整数数组 `nums` **（下标从 0 开始）**和一个整数 `k` 。一个子数组 `(i, j)` 的 **分数** 定义为 `min(nums[i], nums[i+1], ..., nums[j]) * (j - i + 1)` 。一个 **好** 子数组的两个端点下标需要满足 `i <= k <= j` 。请你返回 **好** 子数组的最大可能 **分数** 。
输入：`nums = [1,4,3,7,4,5], k = 3`
输出：`15`
解释：最优子数组的左右端点下标是 (1, 5) ，分数为 `min(4,3,7,4,5) * (5-1+1) = 3 * 5 = 15` 。
```cpp
class Solution {
public:
    int maximumScore(vector<int>& nums, int k) {
        int ans = nums[k], minval = nums[k];
        for(int head = k, tail = k, times = 0; times < nums.size() - 1; times++)
        {
            if((tail == nums.size()) || (head > 0 && nums[head - 1] > nums[tail + 1])) 
                minval = minval < nums[--head] ? minval : nums[head];
            else minval = minval < nums[++tail] ? minval : nums[tail];
            ans = ans > minval * (tail - head + 1) ? ans : minval * (tail - head + 1);
        }
        return ans;
    }
};
class Solution {
public:
    int maximumScore(vector<int>& nums, int k) {
        int ans = nums[k], minval = nums[k];
        for(int coomparedtimes = 0, head = k, tail = k; coomparedtimes < nums.size() - 1; coomparedtimes++)//总的比较次数为nums.size() - 1 次
        {//考虑清楚什么时候只是移动head，什么时候只是移动tail，由此建立判断条件。

/*记区间 [l,r] 对应的分数为 f(l,r) = h(l,r)×(r−l+1)，其中 h(l,r)=min{nums[i]∣l ≤ i ≤ r}，表示区间内的最小元素。因为 l ≤ k ≤ r，可知 h(l,r) ≤ nums[k]。所以在长度tail - head + 1不断变大过程中要想取得尽可能大的分数值，我们需要尽可能使得当前高度最小值接近nums[k]这个初始高度值，毕竟随着更新高度值的过程中新高度总是小于原初始高度值，可知 当前最大分数 = minval * (tail - head + 1) <= nums[k] * (tail - head + 1)。故在移动过程中为了达到使得 当前高度最小值尽可能接近nums[k] 这个目标，我们优先移动方向较大的那一侧（有贪心的思想），从而保证每次更新都是尽可能接近或等于 nums[k] * (tail - head + 1) 这个目标值，最后注意遍历完整个数组一共是nums.size() - 1次作为循环结束条件。*/
```

- [42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)
给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。
![[LeetCode42例题图.png]]
输入：height = `[0,1,0,2,1,0,1,3,2,1,2,1]`
输出：6
解释：上面是由数组 `[0,1,0,2,1,0,1,3,2,1,2,1]` 表示的高度图，在这种情况下可以接 6 个单位的雨水（蓝色部分表示雨水）。 
```cpp
class Solution {
public:
    int trap(vector<int>& height) { 
        int ans = 0, headmax = 0, tailmax = 0, head = 0, tail = height.size() - 1;
        while(head < tail)
        {
            headmax = headmax > height[head] ? headmax : height[head];
            tailmax = tailmax > height[tail] ? tailmax : height[tail];
            ans += headmax > tailmax ? tailmax - height[tail--] : headmax - height[head++];
        }
        return ans;
    }
};
```

- [1574. 删除最短的子数组使剩余数组有序](https://leetcode.cn/problems/shortest-subarray-to-be-removed-to-make-array-sorted/)
给你一个整数数组 arr ，请你删除一个子数组（可以为空），使得 arr 中剩下的元素是 非递减 的。一个子数组指的是原数组中连续的一个子序列。请你返回满足题目要求的最短子数组的长度。
输入：arr = `[5,4,3,2,1]`
输出：4
解释：由于数组是严格递减的，我们只能保留一个元素。所以我们需要删除长度为 4 的子数组，要么删除 `[5,4,3,2]`，要么删除 `[4,3,2,1]`。
输入：arr = `[6,3,10,11,15,20,13,3,18,12]`
输出：8
```cpp
class Solution {
public:
    int findLengthOfShortestSubarray(vector<int>& arr) {
        int len = arr.size(), tail = len - 1;
        while(tail > 0 && arr[tail - 1] <= arr[tail]) tail--;
        if(tail == 0) return 0; //判断特例，这种情况下数组不减

        int ans = tail; // 删除 0 到 tail-1
        for(int head = 0; head == 0 || arr[head - 1] <= arr[head]; head++) //枚举左移动右
        {
            while(tail < len && arr[tail] < arr[head]) tail++; // 此时 arr[head] <= arr[tail]，从 head+1 到 tail-1 可以删除
            ans = ans < tail - head - 1 ? ans : tail - head - 1;
        }
        return ans;
    }
};
```


- [2972. 统计移除递增子数组的数目 II](https://leetcode.cn/problems/count-the-number-of-incremovable-subarrays-ii/)
给你一个下标从 0 开始的 正 整数数组 nums 。如果 nums 的一个子数组满足：移除这个子数组后剩余元素 严格递增 ，那么我们称这个子数组为 移除递增 子数组。比方说，`[5, 3, 4, 6, 7]` 中的 `[3, 4]` 是一个移除递增子数组，因为移除该子数组后，`[5, 3, 4, 6, 7]` 变为 `[5, 6, 7]` ，是严格递增的。请你返回 nums 中 移除递增 子数组的总数目。注意 ，剩余元素为空的数组也视为是递增的。子数组 指的是一个数组中一段连续的元素序列。
参考思路：[灵神思路](https://leetcode.cn/problems/count-the-number-of-incremovable-subarrays-ii/solutions/2577663/shuang-zhi-zhen-on-shi-jian-o1-kong-jian-2hsz)
```cpp
class Solution {
public:
    long long incremovableSubarrayCount(vector<int>& nums) {
        int head = 0, len = nums.size();
        while(head < len - 1 && nums[head] < nums[head + 1]) head++;
        if(head == len - 1) return (long long) len * (len + 1) / 2;

        long long ans = head + 2; // 不保留后缀的情况，一共 head + 2 个
        for(int tail = len - 1; tail == len - 1 || nums[tail] < nums[tail + 1]; tail--)
        {
            while(head >= 0 && nums[head] >= nums[tail]) head--; //枚举 tail 的同时，维护最长前缀的最后一个数的下标 head（满足 a[head] < a[tail]），也就是说，移除的子数组的第一个数的下标至多为 head+1。(由于不能移除空数组，head 与 tail 的中间至少要有一个数, 所以必须要有 head ≤ tail−2。但是 head=tail−1 的情况说明 a 是严格递增数组，已经在前面特判了，所以无需判断 head 和 tail−2 的大小关系。
            ans += head + 2; // 可以保留前缀 a[:head+1], a[:head], ..., a[:0] 一共 head+2 个
        }
        return ans;
    }
};
```


- [1156. 单字符重复子串的最大长度](https://leetcode.cn/problems/swap-for-longest-repeated-character-substring/)
如果字符串中的所有字符都相同，那么这个字符串是单字符重复的字符串。给你一个字符串 text，你只能交换其中两个字符一次或者什么都不做，然后得到一些单字符重复的子串。返回其中最长的子串的长度。
输入：text = "aaabaaa"
输出：6
 1 <= text.length <= 20000
text 仅由小写英文字母组成。
```cpp
class Solution {
public:
    int maxRepOpt1(string text) {
        int ans = 1, count[26] = {0}, len = text.size();
        for(int i = 0; i < len; i++) count[text[i] - 'a']++;

        int head = 0;
        while(head < len)
        {
            int midtail = head;
            while(midtail < len && text[midtail] == text[head]) midtail++; //由于midtail = head使得循环至少执行一次。

            int leftpart = midtail - head, tail = midtail + 1;
            while(tail < len && text[tail] == text[head]) tail++;
            int rightpart = tail - midtail - 1;

            //下面语句等价于ans = max(ans, min(leftpart + rightpart + 1, count[text[i] - 'a']));
            ans = ans > (leftpart + rightpart < count[text[head] - 'a'] ? leftpart + rightpart + 1 : leftpart + rightpart) ? ans : (leftpart + rightpart < count[text[head] - 'a'] ? leftpart + rightpart + 1 : leftpart + rightpart); 

            head = midtail;
        }

        return ans;
    }
};
```
